The BTCFi campaign uses Neutron's integrated blockchain infrastructure to deliver Bitcoin DeFi strategies through transparent, on-chain reward tracking.

## System Architecture

<AccordionGroup>
  <Accordion title="Points System" icon="chart-line" description="On-chain reward tracking and distribution infrastructure" defaultOpen={true}>
    **Points Contract**: On-chain smart contract for reward tracking and distribution
    - Stores user points and reward calculations on-chain
    - Supports Neutron address formats
    - Enables transparent reward verification

    **Points Crawler**: Modified version of [Droplets](https://droplets.drop.money/) points campaign functionality
    - Gathers data on deposit size and duration
    - Publishes data on-chain to the points contract
    - Uses daily snapshots for fair reward distribution

    **Reward Distribution**: Dollar-denominated rewards converted to NTRN at phase end
    - Protects users from token price volatility during phases
    - Aligns campaign costs with network growth
  </Accordion>

  <Accordion title="Address Linking System" icon="link" description="Simplified boost management on Neutron">
    **Boost Pointer Contract**: Links Neutron-based boosts to deposit addresses
    - Accepts Neutron address formats
    - User-controlled "pointing" system for boost coordination
    - No unbonding periods - purely accounting mechanism

    **Simplified Architecture**: All deposits and boosts on Neutron
    - Direct Neutron deposits to positions (Amber, Supervaults)
    - Boosts apply to the same Neutron address
    - Streamlined reward calculation system
    - Complete implementation: [Address Linking System](/btcfi/technical/address-linking)
  </Accordion>
</AccordionGroup>
