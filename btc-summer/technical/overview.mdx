The BTC Summer campaign leverages Neutron's integrated blockchain infrastructure to deliver sophisticated Bitcoin DeFi strategies through a robust, transparent, and scalable technical architecture.

---

## System Components

### Points & Rewards Infrastructure

**Points Contract**: Smart contract system for transparent reward tracking and distribution
- Stores user points and reward calculations on-chain
- Supports both Ethereum and Neutron address formats
- Enables real-time reward projections and verification

**Reward Distribution**: Dollar-denominated rewards converted to NTRN at epoch end
- Protects users from token price volatility during epochs
- Aligns campaign costs with network growth
- Enables predictable reward planning

### Cross-Chain Coordination

**Address Linking System**: User-controlled cross-chain reward coordination
- Boost Pointer Contract for linking rewards across networks
- Support for both EVM and Neutron address formats
- User-controlled "pointing" system for boost coordination

**Bridge Infrastructure**: Secure asset bridging for Ethereum vault participants
- Automated bridging through established protocols
- Asset deployment to Neutron DeFi positions
- Withdrawal processing back to user wallets

### DeFi Integration Layer

**Protocol Connectivity**: Direct integration with Neutron's DeFi ecosystem
- Amber Protocol for lending and leveraged strategies
- Supervaults for automated market making
- Mars Protocol for perpetuals trading (integration pending)

**Real-Time Data**: Live position tracking and reward calculations
- Daily snapshots for fair reward distribution
- Cross-protocol position aggregation
- Transparent on-chain verification

## Security Considerations

### On-Chain Transparency
- All points and rewards data stored on-chain
- Public verification of reward calculations
- No centralized backend dependencies for core functions

### Manipulation Prevention
- Random snapshot timing prevents gaming
- Time-averaged calculations reduce manipulation impact
- Cross-protocol validation ensures data accuracy

### Smart Contract Security
- Established protocols with proven track records
- Multiple security audits for critical components
- Gradual rollout with monitoring and safeguards

## Data Flow

### User Deposits
1. **Ethereum Path**: Vault → Bridge → Neutron Protocol → Points Tracking
2. **Neutron Path**: Direct Protocol → Points Tracking
3. **Reward Calculation**: Daily snapshots → Points accumulation → Epoch distribution

### Boost Mechanisms
1. **NTRN Locking**: Lock contract → Receipt NFT → Boost calculation
2. **Address Linking**: Boost pointing → Cross-chain coordination → Reward enhancement
3. **Verification**: On-chain validation → Real-time boost application
