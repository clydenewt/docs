## Points API Integration

<Warning>
The Points API is currently in development. Specifications below are preliminary and subject to change.
</Warning>

### Planned API Endpoints

**Base URL**: [API endpoint will be announced when available]

#### User Data Endpoints
```
GET /points/{address}     # User points and rewards
GET /positions/{address}  # Eligible positions
GET /boost-status/{address} # Boost configuration
```

#### Campaign Data Endpoints
```
GET /campaign/status      # Current phase and campaign status
GET /epochs              # Phase information
GET /eligible-protocols  # Qualifying protocols and multipliers
```

### Current Integration Options

While the dedicated API is in development, integrators can:
- **Query smart contracts directly**: Use CosmWasm query methods
- **Use Neutron RPC**: Access on-chain data via standard Cosmos RPC
- **Monitor events**: Listen to contract events for real-time updates

See [Neutron Developer Documentation](/developers/overview) for current integration patterns.

## Asset Issuer Integration

### For BTC LST Issuers

Asset issuers can integrate their BTC LSTs with the campaign to:
- Track performance of their assets in the campaign
- Provide additional rewards to their users
- Gain exposure to Neutron's DeFi ecosystem

### Integration Process
1. **Initial contact**: Reach out through official channels
2. **Technical review**: Asset compatibility assessment
3. **Integration planning**: Timeline and requirements discussion
4. **Testing phase**: Sandbox environment testing
5. **Production deployment**: Live integration and monitoring

## Partnership Integration

### Partnership Opportunities

1. **Frontend Partners**: Build alternative interfaces for campaign participation
2. **Wallet Integrations**: Native campaign support in wallet applications

4. **Protocol Partners**: DeFi protocols wanting to collaborate on strategies

### Technical Requirements
- **Frontend development**: Ability to build user interfaces

- **Cross-chain coordination**: Support for multi-network users
