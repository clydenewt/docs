## System Requirements

For detailed system requirements and setup instructions, see the [Node Setup Guide](/operators/running-a-node#system-requirements).

Quick reference:
- 4+ CPU cores
- 16+ GB RAM (64GB recommended for validators)
- 500+ GB SSD storage
- Ubuntu 20.04 or later
- Go 1.23.4 for building from source
